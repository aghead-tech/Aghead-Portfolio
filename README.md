## ⚙️ Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

This project was developed and tested with Node.js 24.

### Clone the Repository

```bash
git clone git@github.com:aghead-tech/Aghead-Portfolio.git
```

Then enter the project:

```bash
cd Aghead-Portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## 🏗️ Production Build

Create an optimized production build:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```
